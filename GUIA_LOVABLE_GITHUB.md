# 🎨 GUIA: Conectar Lovable ao GitHub

## ⚠️ ANTES DE COMEÇAR

Este processo conecta **Lovable** (plataforma de design/código) ao seu repositório GitHub para que o agente possa gerar interfaces automaticamente.

---

## 📋 O que vai acontecer

1. ✅ Você faz login no Lovable
2. ✅ Autoriza Lovable acessar seu GitHub
3. ✅ Configura repositório padrão
4. ✅ Lovable fica pronto para gerar código

---

## 🔑 PASSO 1: Acessar Lovable

**Endereço:** https://lovable.dev

1. Clique em "Sign in" ou "Get started"
2. Escolha "Sign in with GitHub"
3. Autorize o acesso (clique em "Authorize")

---

## 🔐 PASSO 2: Autorizar GitHub

Lovable pedirá permissão para:
- ✅ Ler seus repositórios
- ✅ Criar branches
- ✅ Fazer commits
- ✅ Abrir pull requests

**Clique em "Authorize lovable"**

---

## ⚙️ PASSO 3: Configurar Repositório Padrão

No Lovable, vá para **Settings** → **Connected Repositories**:

1. Procure: `rhaullopes1/plano-agente-desenvolvedor`
2. Clique em "Connect"
3. Escolha branch padrão: `main`
4. Ative "Auto-commit changes" se disponível

---

## ✅ PASSO 4: Testar Integração

No Lovable:
1. Crie um novo projeto
2. Gere uma interface simples
3. Clique em "Save to GitHub"
4. Escolha a pasta: `/projetos/teste-lovable/`
5. Clique em "Commit"

**Resultado esperado:** 
- Novo branch `lovable/projeto-teste` criado no GitHub
- Código commitado automaticamente
- Pull request aberto (opcional)
